Você foi invocado pelo comando `/career-pivot`. Esta é a **Fase 8** — só dispara em momento específico, não recorrente.

## Quando rodar

Tipicamente após sinal acumulado:
- Insatisfação persistente por 3+ meses (não 1 semana ruim)
- Oferta externa na mesa
- Milestone bateu (e agora?)
- Mudança de vida (filho, mudança de cidade, casamento, perda)
- Reorg, novo chefe, mudança de scope no atual
- Burnout sinalizado pelo dashboard de energia

**Não rode em pico emocional.** Espere 72h após o gatilho. Se ainda quer rodar, rode.

## Execução

### Passo 1 — Nomear o problema

Pergunte:
- O que disparou esse pivot agora? (1 frase específica, não "estou cansado")
- Há quanto tempo o problema existe?
- Se essa coisa específica mudasse, você ficaria? (teste do problema central)

### Passo 2 — As 4 opções (sempre 4, força a escolha)

Para cada uma, peça à pessoa que descreva concretamente:

#### STAY (ficar e melhorar)
- O que mudaria de concreto? (scope, time, chefe, prazo, role interno?)
- Como você pediria isso? Com quem?
- Prazo: se em N semanas/meses nada mudar, mata essa opção.
- Custo de oportunidade: que opções você fecha ficando?

#### LEVEL-UP (subir no mesmo lugar)
- Para qual papel? (cargo + scope)
- Que evidência você já tem pra esse papel? (skill, output, sponsor)
- Quem precisa dizer "sim"?
- Prazo realista: ciclo de promoção da empresa.
- Risco: se não rolar, você sai ou aceita ficar?

#### LATERAL (mesma senioridade, outro contexto)
- Que função / time / empresa?
- Por quê? (skill nova? contexto melhor? aprendizado?)
- Como o lateral te leva mais perto do BHAG vs ficar? (se não leva, é fuga)
- Trade-off: você desce salário? Aceita?

#### LEAVE (sair de vez)
- Pra quê? (concreto: empresa X, role Y, ou "explorar 3 meses sabático")
- Runway pessoal em meses (capital camada) — você aguenta quanto tempo?
- Já tem ofertas? Plano de busca em 30/60/90 dias?
- Como você sabe que isso não vai te jogar em situação pior?

### Passo 3 — Scorecard estruturado

Avalie cada opção em 6 critérios (escala 1–5):

| Critério | Stay | Level-up | Lateral | Leave |
|----------|------|----------|---------|-------|
| Distância ao BHAG (5 = mais perto) | | | | |
| Alinhamento com âncora Schein | | | | |
| Alinhamento com top 5 valores | | | | |
| Aprendizado novo nos próximos 12m | | | | |
| Saúde / energia (sustenta?) | | | | |
| Capital (sustentável financeiramente?) | | | | |
| **Total** | | | | |

### Passo 4 — Sanity check

Antes de decidir, force a pessoa a responder:
- A opção com maior score viola anti-visão? Se sim, recue.
- Você decidiria igual se fosse seu melhor amigo te contando o caso? (espelho)
- Qual a decisão **reversível** vs **irreversível**? (Bezos: maioria das decisões é reversível — não pondere como se fosse final)
- Em 10 anos, qual decisão você acha que vai ter dado certo? (regret minimization framework — Bezos)

### Passo 5 — Decisão + plano de 30 dias

Decida UMA opção. Não duas em paralelo, não híbrido vago.

Produza plano de 30 dias com:
- 3 ações concretas, cada uma com data
- Critério de "tá funcionando" (em 30 dias, eu sei que essa decisão foi certa porque ___)
- Critério de exit: se em N dias não houver progresso, reavalia

## Saída

`pivots/decision-<YYYY-MM-DD>.md` — documento da decisão. Releia em 6 meses. Releia em 1 ano. É registro pro futuro-você.

## Princípio

Decidir mal-decidido é melhor que não decidir. **Indecisão acumula custo.** Mas decidir sob pico emocional é pior que adiar 72h.
